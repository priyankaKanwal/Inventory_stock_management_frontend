1Bootstrap & First Load
What happens from the moment the URL hits the browser until the first screen is painted.

STEP 1 — Browser loads index.html

Parses the HTML shell. Mount point is <app-root></app-root>. The bundled main.js script is fetched and executed.

STEP 2 — main.ts executes

platformBrowserDynamic().bootstrapModule(AppModule) → bootstraps the root NgModule (module-based Angular, NOT standalone).

STEP 3 — AppModule initializes

Registers RouterModule.forRoot(routes) and provides HttpClient with the global AuthInterceptor. Bootstraps AppComponent.

STEP 4 — AppComponent renders

Renders the root <router-outlet> and hands control to the Angular Router to resolve the current URL.

5Authorization & Guards
Two functional guards gate every navigation. A third layer hides admin controls in the UI.

♠ authGuard — canActivateFn (root)

  • Reads localStorage.access_token
  • Token exists → return true
  • No token → return UrlTree('/login')

♠ roleGuard — canActivateFn(route)

  • Reads route.data['roles'] (e.g. ['ADMIN'])
  • Reads localStorage.role
  • Role in allowed list → return true
  • Otherwise → UrlTree('/login')

♠ UI-level role check

  • role = localStorage.getItem('role')
  • *ngIf="role === 'ADMIN'" → Add/Edit/Delete buttons visible
  • STAFF users see a read-only list
// roleGuard logic (applied to every feature route)
const userRole = localStorage.getItem('role');
const allowed = (route.data['roles'] as string[]).map(r => r.toUpperCase());
if (userRole && allowed.includes(userRole.toUpperCase())) return true;
return router.createUrlTree(['/login']);

15State Management & localStorage
No centralized store (no NgRx/NGXS). The app uses fetch-on-navigate with component-local state, plus a small localStorage persistence layer.

Fetch-on-navigate

  • Every container fetches fresh data in ngOnInit
  • Data held in component-local arrays/properties
  • After create/update → navigate to list → fresh fetch

Optimistic updates

  • Delete: confirm → API call → splice from local array
  • No re-fetch after delete
  • Name resolution via in-memory maps (category/supplier)

Template state pattern

  • isLoading: boolean → spinner
  • error: string → error box
  • items: T[] → *ngFor render
